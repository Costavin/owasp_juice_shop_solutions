# NFT Takeover

From the `/#/administration` page, we cna find the endpoint `juicy-nft`. Here it is required we put the private key in order to own the account. However, we can notice a list of apparently useless words. But if we squint enough our eyes, we can notice they make up the passphrase seed for the private key. We can choose our favourite tool, and convert the list of words to an ethereum private key.
